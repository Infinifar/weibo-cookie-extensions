微博 Cookie 同步设置

管理微博登录态与青龙 Open API 连接

v1.0.0

青龙地址填写面板根地址，例如 https://ql.example.com，不要填写末尾的 /open。

使用方式

  1. 在青龙“系统设置 → 应用设置”创建应用，取得 Client ID 和 Client Secret。
  2. 安装后在微博页面登录，点击扩展图标中的“读取当前账号并同步”。
  3. 青龙脚本继续读取 WEIBO_CONFIGS_JSON；扩展会按 UID 更新或追加账号。

Cookie 失效后无法静默生成新 Cookie；重新登录或扫码后，扩展会在 Cookie 变化时再次同步。mTLS 客户端证书由 Chrome/系统证书库提供，扩展本身不保存私钥。
